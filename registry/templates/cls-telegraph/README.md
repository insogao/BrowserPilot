# 财联社电报模板

抓取财联社电报页（cls.cn/telegraph）的最新快讯流：每条含时间（HH:MM:SS）、【标题】、正文。

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| limit | number | 否 | 最多条数（默认 20，上限 50） |

## 说明

- 首屏 SPA 渲染较慢，模板内置 3.5s 等待。
- 电报条目容器为工具类（`.p-t-20.p-b-20`），站点改版时此选择器可能失效——以真实 smoke 为准。
- 相关：`stock-announcements`（个股公告，慢变量）。
