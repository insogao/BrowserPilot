BrowserPilot

安装时浏览器会一次性提示以下权限，本扩展运行中不会再请求任何权限。

权限逐条解释

权限用途
debugger只在 AI 执行需要 CDP 的命令后附加，用于操作目标标签页（受信点击/填表/求值）；人工接管或后台 stop 命令会解除。
nativeMessaging用于你本机的外部 AI/CLI（如 Codex / 其它 Agent）连接本插件，数据不出本机。
scripting向页面注入观测/轻增强脚本（浏览档 L0）。
tabs标签导航、查询、监听激活/关闭。
storage本地保存会话状态（仅本机）。
downloads下载媒体/文件（如需）。
alarms周期唤醒 service worker，维持本机 host 连接。
站点权限 <all_urls>仅在任务涉及标签页时使用，不做后台收集。
调试横幅说明：接管标签后会看到「此浏览器正被调试」横幅，这是 Chrome 调试 API 的固有提示；纯浏览（L0）无横幅。

多 profile 使用

浏览器按 --profile-directory="Profile N" 启动多个 profile。每个用到的 profile 需单独安装本插件，各自安装后通过「Copy Skill」导出对应说明，拷贝给对应的 AI 对话即可。首次启动后插件会缓存 profile 信息，官方 client 后续可自动拉起该 profile。

常用命令（外部 AI 对接）

连接本机 com.browserpilot.browseragent host 后，先从 popup 复制 Copy Skill 文档。当前可用：ping / version / get_profile / export_guide / snapshot(level=L0) / click / fill / js / drainEvents / screenshot / list_tabs / run_template。
