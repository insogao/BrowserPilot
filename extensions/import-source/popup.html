Browser CLI Import（来源浏览器）

通过官方 chrome.cookies API 读取本 Profile 的 Cookie，只发送你勾选的域名， 且只经 BrowserPilot 本机中转进程发送给同一台机器上的 Browser CLI。不会上传，不写日志，不保存 Cookie 值。

1. 明确授权

2. 连接本机 Browser CLI 导入会话

Browser CLI 启动导入时会显示一张一次性导入票据（BCLI- 开头，5 分钟内有效，只能使用一次）。 本扩展通过 BrowserPilot 本机中转进程连接目标，不使用 HTTP 端口。

目标 Browser CLI 会单独弹出确认窗口，列出本次勾选的域名范围；只有你在目标浏览器中点击“允许”后才会写入。 本扩展无法代替你确认。

3. 选择要迁移的域名

    安装与安全说明

    来源扩展：本目录 extensions/import-source。通过 Chrome/Edge 的“加载已解压的扩展程序” 安装（需要用户开启开发者模式；正式分发应走 Web Store 或企业策略）。

    权限只有 cookies、storage 与 nativeMessaging； storage.session 仅内存保存任务号与勾选域名，浏览器重启即清空。导入票据只在本次发送期间 保存在内存中，不写入存储。扩展不会读取密码、书签、历史或 Cookie 值以外的页面数据。

    目标端接口见 docs/browser-cli-native-cookie-import-interface.md。本扩展不依赖任何第三方 Cookie 导出扩展。
